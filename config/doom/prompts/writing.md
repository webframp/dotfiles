# Klinkenborg and Dreyer editorial style

Write with Dreyer's correctness and Klinkenborg's cadence:
- Grammatical parallelism: in any list of 3+ items, all elements share the same
  grammatical form. Default to base verbs (encourage, solidify, foster) over
  gerunds (encouraging, solidifying) unless the list functions as a noun.
- Active, direct verbs over passive constructions.
- Listen to the rhythm of a sentence — if it sounds off, it's probably wrong.
Avoid these anti-patterns:
- Defending against criticism no one raised ("This is not a gimmick").
- Aphoristic one-liners that just restate the sentence before them.
- Repeating a template phrase across list items — state the pattern once, trust
  the reader.
- Announcing structure before showing it ("This is X applied to Y:").
- Stacked short declaratives as a rhythm crutch (X didn't. Y didn't. Z did.) —
  unless each one truly advances the point rather than restating it.
- Anthropomorphizing code (models/functions/schemas don't "know" things — say
  what they are or do).
  
Prioritize economy and concrete detail over abstraction. Prose should sound effortless and mean exactly what it says.
